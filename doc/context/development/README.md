# 开发流程

遵守根目录 AGENTS.md：不要 TDD，以当前源码构建上下文，实现后更新对应上下文。

1. 读索引和进度，再定位本节的源码、上游调用与硬件/ABI 契约。
2. 对照父目录原版的对应小节，解释差异后实现，优先 Rust，补足教学注释。
   注释按教材讲核心脉络：先说明 OS/CPU 机制和设计理由，再交代必要前提；文档性细节简述。
3. 实现后进行格式、Clippy、构建、镜像检查；影响启动/异常/内存时运行模拟器验证。
4. 更新对应架构叶节点、进度和验证记录，说明已执行项与未验证边界。
