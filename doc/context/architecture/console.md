# 图形文字输出

源码：`src/kernel/console.rs`、`font.rs`；调用入口 `kprint!(颜色, 格式串, 参数...)`。
原 `printk.c` 的 C 可变参数/固定字符串缓冲改为 `core::fmt::Write`，无堆分配。
常用十六进制地址用 `{:#018x}`，支持 Rust 格式化的数字、字符串和宽度。
不保留 C `%n`、可变参数或 `vsprintf` ABI，当前调用点已全部迁移。

Loader 在物理 `0x8200` 交接实际选定模式。控制台读取宽、高、pitch、32 bpp、
RGB 位域和物理帧缓冲地址，验证为 BGRX8888、有效线性帧缓冲且不超出 16 MiB 显存窗口。
按 pitch 寻址，MMIO 像素写入使用 `write_volatile`。
字体保留原 `font.h` 全部 4096 字节（256×16），最高位对应左侧像素。
只支持该单字节字库，不支持中文/Unicode 字形；教学注释可以用中文，屏幕输出用 ASCII。

光标以字符格计数，8×16 像素；支持换行、回车、退格、8 格 tab 和自动换行。
越过最后一行后回到顶部覆盖，保持教材阶段行为，没有滚屏。
修正原 C `screen_height()` 取 x_resolution 及退格时像素/字符单位混用的问题。

所有输出同时写 0xe9 debugcon。帧缓冲输出用原子 BUSY 防止异常重入构造重叠可变引用；
重入者只输出 debugcon、不等待锁，避免异常死锁。初始化前 panic 也能看到调试日志。
本阶段单核、没有启用外部 IRQ；以后并发输出需重新设计中断与锁的策略。
