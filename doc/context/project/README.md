# 项目与学习方式

MikoOS 是《一个64位操作系统的设计与实现》的逐章学习和手敲项目，后续由 AI 持续开发。
原版代码和笔记位于 `../The-design-and-implementation-of-a-64-bit-os`，不修改该目录。
原版用来理解硬件流程；当前仓库决定真实接口、构建方式和已完成范围。

尽可能使用 Rust，当前为稳定工具链、无第三方依赖的 `no_std` 内核。
硬件操作集中到薄封装中，教学阶段保留可见的位域与指令。可以按学习需要引入 crate，
但不能为了换语言而直接替换整条启动链，跳过 FAT12、模式切换等学习内容。
